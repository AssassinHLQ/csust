# 剧情语音（`res://story/voice/`）

这个目录是**配音文件的家**。剧本里用一行 `@voice 名字` 点它，播放到那句台词时自动响。

## 三步

1. 把音频丢进这个目录（`ogg` / `wav` / `mp3` 都行，`ogg` 最省体积）。
2. 打开 `story/开场.txt`，在**要配的那句上面**加一行：

```
@voice 开场_01
* 2067 年。世界陷入一场前无古人、后无来者的毁灭性灾难。
```

3. 存盘，F5 进游戏。（文件是**刚丢进来的**也没关系，编辑器还没导入也能响。）

## 名字怎么起

| 你写 | 实际找的文件 |
|---|---|
| `@voice 开场_01` | `开场_01.ogg` → `开场_01.wav` → `开场_01.mp3`（按这个顺序，先找到哪个用哪个） |
| `@voice 开场_01.wav` | 只认 `开场_01.wav`，别的后缀**不会**兜底 |
| `@voice 优香/02` | `优香/02.ogg`（可以分目录） |
| `@voice ../secret` | ❌ 报错（名字只认 `story/voice/` 里面） |

名字可以是中文，但**别带空格以外的怪符号**（`:` `\` `*` `?` 之类会被拒绝并报错）。

## 三条行为（都是刻意的）

- **缺文件不报错、不中断演出**，只在控制台 warning 一次。配音是锦上添花，
  不该因为少一个文件就整段剧情不播。
- **翻页立刻停**上一条配音，不会两句话叠在一起响。
- 走 `Master` 总线 —— 设置界面里的主音量管得到它。

## 检查

```powershell
& <godot> --path . --script res://scripts/_verify_story.gd -- --splat=off
```

- 剧本里点名了、但文件不存在的，会在第 4 节列出来（`[提醒] 缺 N 个语音`）；
- 第 8 节会真造一个 wav、真播一遍、真断言「翻页后停了」。

## 已经配好的

开场三句旁白（`story/开场.txt` 每句上面一行 `@voice`）：

| 名字 | 文件 | 时长 | 对应那句 |
|---|---|---|---|
| `开场_01` | `开场_01.ogg` | 6.48 s | 2067 年。世界陷入一场前无古人、后无来者的毁灭性灾难**当中**。 |
| `开场_02` | `开场_02.ogg` | 6.97 s | 为了拯救长沙理工大学，学生们把老师护在身后，铤而走险，对抗「色彩」。 |
| `开场_03` | `开场_03.ogg` | 6.32 s | 她们集结在最后的基地——画室 609，商讨着如何击败敌军。 |

源文件是 `D:\1.mp4` / `2.mp4` / `3.mp4`（AAC 立体声 44.1 kHz），转换命令：

```
ffmpeg -i N.mp4 -vn -c:a libvorbis -q:a 5 开场_0N.ogg
```

## 以后要加 BGM / 音效

现在只接了「台词配音」。想做 BGM 就是再加一条指令（`@bgm`），
照 `story_script.gd` 里 `@voice` 的写法抄一遍即可。
