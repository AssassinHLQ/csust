#  长沙理工：2067 —— 开场剧情
#
#  这个文件就是剧本。**直接用记事本 / VS Code 打开改字**，存成 UTF-8，
#  然后 F5 进游戏就会自动播这一段。
#
#  ── 只认五种写法 ────────────────────────────────────────────────────────
#
#     # 随便写的注释                  整行以 # 开头 → 不播
#     名字: 台词                      名字 + 冒号 + 正文
#     名字：台词                      半角 : 和全角 ：都行
#     * 旁白                          以 * 开头 → 没有名字的旁白
#     @命令 参数                      以 @ 开头 → 指令
#
#  认不出来的行**不会静默跳过**：启动时会在控制台报错，并告诉你是第几行、
#  原行长什么样。剧本有任何一处错误就整段不播（宁可不出，也别演半截）。
#
#  ── 四个命令 ────────────────────────────────────────────────────────────
#
#     @wait 1.2          停一拍。画面不动，等 1.2 秒自己往下走。
#     @clear             清空对话框，停半秒，用来分段。
#     @speed 45          从这行往下，打字速度改成 45 字/秒（默认 30）。
#     @end               到此为止，后面的都不播。
#
#  ── 播放时 ──────────────────────────────────────────────────────────────
#
#     空格 / 回车 / 鼠标左键        第一下把当前这句打完，第二下翻到下一句
#     游戏是暂停的                  同伴不会开枪、Boss 不会打你；播完自动恢复
#     Esc                          照样能开设置界面（设置界面优先，剧情会等着）
#
#  ── 写的时候注意 ────────────────────────────────────────────────────────
#
#     · 一行 = 一句。想换行就多写一行，不用打 \n。
#     · 只有**整行**以 # 开头才是注释。`优香: 你好 # 备注` 里的 # 是台词的一部分。
#     · 台词只在**第一个**冒号处切开，所以正文里随便打冒号（`他说：好` 没问题）。
#     · 一行别写太长：对话框正文区最多放两行（一行约 44 个汉字），超了会被裁掉。
#       改完跑一次自检就能看到「哪一行太长」——见 README 里那一节。
#
