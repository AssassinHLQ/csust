# 开场 PV 图片

开场现在直接读取项目内 `_arisu_captures/_shots/` 的 PNG，按文件名字典序循环播放。
此目录与 `../pv_hd/` 的旧图片已不参与开场播放。

## 更换图片

1. 将 PNG 放入 `_arisu_captures/_shots/`，文件名决定播放顺序。
2. 下次启动游戏时自动更新列表；同目录的元数据文本不参与播放。
3. 保留每张 9 秒、交叉淡化、进度条和点击开始流程。

`_arisu_captures/` 的图片已纳入 Windows 导出，本地与打包版使用同一组开场图。Git 忽略规则只影响版本管理，不影响游戏导出；PNG 无需加入 Git 即可打包。

## 音乐

音乐仍为 `assets/music/pv_theme.mp3`，循环播放直到点击开始。
缺少图片时仍沿用视频、帧序列、渐变背景的回退流程。
