# `assets/music/` —— 背景音乐投放目录

这个目录下的**音频文件不进仓库**（`.gitignore` 已排除），
但**导入配置 `*.ogg.import` 会进仓库** —— 循环开关存在那里面，
克隆者只要把音频按下面的文件名放进来，就直接是循环的，不用再改任何设置。

## 需要放什么

| 文件名 | 用在哪 | 来源 |
|---|---|---|
| `shop_theme.ogg` | 商店「柴关电脑城」的 BGM（走进去开、走出去停） | UNDERTALE「Tem Shop」，© Toby Fox / Materia Collective |
| `gamedev_theme.ogg` | 游戏开发部活动室的 BGM（走进房间开、走出去停） | 「碧蓝档案OST Vol.1」P70「Pixel Time（游戏开发部）」，© NEXON Games / Yostar |
| `esports_theme.ogg` | 电竞房的 BGM（走进房间开、走出去停；房子买回来之前不出声） | 「碧蓝档案OST Vol.1」P8「Colorful Mess」，© NEXON Games / Yostar |
| `art609_theme.ogg` | 画室 609 的 BGM（范围按「出门」定，与泼溅释放同一套边界） | 「碧蓝档案OST Vol.1」P37「Lemonade Diary（咖啡厅）」，© NEXON Games / Yostar |

**只有本地放好这些文件，对应的房间才有音乐**。没有它时不会报错：
`scripts/music.gd` 会 `push_warning` 一次然后静默跳过，游戏照常跑
（和 `assets/ui_sprout/`、`assets/ui_font/` 一样的处理）。

## 不做淡入淡出（2026-11-11）

用户：「不要淡入淡出了，所有的」。

`scripts/music.gd` 的 `FADE_DEFAULT` 从 1.2 s 改成 **0**：进/出房间都是**硬切**。
实测出门那一帧就停（原来要等 1.2 s 淡完）。`play()` / `stop()` 的 `fade` 参数
还留着 —— 以后想给某个场景单独恢复淡化，调用时传秒数即可，不用改结构。

自检里有一条断言盯着这件事（`Music.FADE_DEFAULT` 必须 ≤ 0），防止谁手一滑改回去。

## 怎么生成这个循环

源文件是比较长的一条（现在用的那版是 45.44 s），**不能直接按整数秒切**——
切在整数秒上会在接缝处「咔」一下。要先用自相关量出曲子自身的循环周期，
再切在周期的整数倍上。

工程里带了工具，一条命令复现：

```bash
python tools/audio/make_loop.py \
  "<你的源文件>" \
  "$TEMP/shop_loop.wav" \
  --target 40

# 再编码成 Ogg Vorbis（Godot 吃这个格式，q5 约 127 kbps）
ffmpeg -i "$TEMP/shop_loop.wav" -c:a libvorbis -q:a 5 -ar 44100 assets/music/shop_theme.ogg
```

现在的这一版实测数值（`make_loop.py` 的输出）：

```
自相关循环周期 P = 10.0524 s
选定 L = 40.20943 s（= 4 × P，误差 0.0000 ms）
  → 与开头的波形相关系数 r = +0.6601
  → 接缝跳变 0.000610（曲子内部相邻样点平均跳变 0.0126）
环绕交叉淡化 25 ms（等功率 sqrt 曲线）
峰值归一化到 −1 dBFS
```

⚠️ 为什么是 **40.20943 s** 而不是用户说的整数 40 s：差 0.21 s 听不出长短，
但切在 40.20943 上接缝相关系数 +0.66，切在 40.000 上只有 +0.06、
跳变是内部平均的 1.8 倍（会「咔」）。工具默认就是在目标值附近扫出最好的那个点。

## 游戏开发部那首（`gamedev_theme.ogg`）

源文件 131.1927 s（320 kbps MP3，`「碧蓝档案OST🎵」音乐合集~Vol.1（320K）_P70_Pixel Time（游戏开发部）_音频.mp3`）。

⚠️ **循环点 = 用户 2026-11-12 指定的「裁掉最后 1.00 s」**（源自 2026-11-11 那句
「只需要裁掉最后两秒就可以循环，就是游戏里面的效果」，之后两次微调）：
取**前 130.1927 s（2:10.19）**，硬裁、不做交叉淡化。

```python
import sys; sys.path.insert(0, "tools/audio")
import make_loop as ml
x = ml.load_audio(源文件)                    # 131.1927 s
y = x[:int(round(130.1927 * ml.SR))]         # 硬裁，不 make_seamless
# 再按 -1 dBFS 归一化成 16 bit wav，交给 ffmpeg 编码
```

实测数值：

```
内部相邻样点平均跳变 = 0.043299
选定 L = 130.1927 s（裁掉最后 1.0000 s）
  → 环绕跳变 0.000000（= 内部平均的 ×0.000）
  → 斜率差 0.000000
峰值归一化到 −1 dBFS
```

**这个点是完全连续的**（跳变和斜率差都是 0），硬接一点「咔」都不会有 ——
所以更不需要交叉淡化。

**演变记录**（同一条曲子切过四版，别再绕回去）：
`119.9993 s`（错，按 15 × 8 s 周期切、多砍了 9 s 曲子）
→ `129.2292 s`（「裁掉最后两秒」）→ `129.9900 s`（2:09.99，需裁 1.2027 s）
→ **`130.1927 s`（裁掉 1.00 s，本轮）**。

## 电竞房那首（`esports_theme.ogg`）

源文件 111.8293 s（320 kbps MP3，`「碧蓝档案OST🎵」音乐合集~Vol.1（320K）_P8_Colorful Mess_音频.mp3`）。

**这首不能用「周期整数倍」那套直接套**，原因有两个：

1. 自相关最强峰在 22.3256 s，但相关系数只有 **0.40** —— 曲子不是严格周期结构；
2. **结尾没有淡出**：末 10 s 的 RMS 0.145，和全曲 0.155 差不多。
   直接整首循环会从响亮的结尾硬切回安静的前奏（开头 5 s 的 RMS 只有 0.100）。

所以改成「在曲子内部找一个接缝本来就干净的点」：先按 `--target 40` 让工具报出周期，
再用 `make_loop.py` 里的函数（`load_audio` / `make_seamless`）扫一遍候选长度，
判据不是「周期整数倍」而是**环绕交叉淡化之后还剩多大的跳变**。

```python
import sys; sys.path.insert(0, "tools/audio")
import make_loop as ml
x = ml.load_audio(源文件)
y = ml.make_seamless(x, int(round(92.070 * ml.SR)), 25.0)   # 92.070 s
# 再按 -1 dBFS 归一化成 16 bit wav，交给 ffmpeg 编码
```

实测数值：

```
自相关周期候选：P = 22.3256 s（ac 0.40）/ 5.5814 s（0.39）/ 11.1628 s（0.37）
   —— 都不是干净的整数周期，所以不走「整数倍」那条路
选定 L = 92.0700 s（全曲的 82.33%，4.124 × P）
  → 与开头 4 s 的相关系数 r = +0.5647（20~106 s 全长度扫描里最高的一档）
  → 淡化前接缝跳变 0.005445（曲子内部相邻样点平均跳变 0.0413，×0.13）
环绕交叉淡化 25 ms（等功率 sqrt 曲线）
  → 淡化后环绕断点 0.002878（内部平均的 ×0.07）
峰值归一化到 −1 dBFS
```

切掉的末尾约 19.8 s 主要是收尾段落 —— 那一段本来也不是循环要的。

## 画室 609 那首（`art609_theme.ogg`）

源文件 154.1547 s（320 kbps MP3，`「碧蓝档案OST🎵」音乐合集~Vol.1（320K）_P37_Lemonade Diary（咖啡厅）_音频.mp3`）。

```python
import sys; sys.path.insert(0, "tools/audio")
import make_loop as ml
x = ml.load_audio(源文件)                     # 154.1547 s
y = x[:int(round(143.9998 * ml.SR))]          # 硬裁，不 make_seamless
# 再按 -1 dBFS 归一化成 16 bit wav，交给 ffmpeg 编码
```

实测数值：

```
自相关循环周期 P = 8.00000 s（零误差）
选定 L = 143.9998 s = 18.00 × P（裁掉最后 10.1549 s）
  → 环绕跳变 0.000015（= 内部相邻样点平均跳变 0.009757 的 ×0.002）
  → 斜率差 0.002563
  → 切点前后 0.3 s 的 RMS：0.163 / 0.207（切在乐句里，不是静音处）
峰值归一化到 −1 dBFS
```

**为什么切在 144 s 而不是别处**：这首 154.15 s，但 153.6 s 之后就开始淡出到
数字静音了（末 0.5 s 的 RMS 只有 0.0006~0.003），剩下的是收尾。
143.9998 s 正好是 **18 个完整周期**，是歌曲自身的循环边界 —— 切在这里能整段循环，
切在末尾静音里则会「先空半秒再跳回开头」。

**范围怎么定**：不是 Area3D 盒子，而是复用 `splat_scene.gd::_is_inside_room()` ——
也就是「出房间就释放泼溅显存」用的那套判据（`RoomCollision` 墙盒内沿 + 高度窗口
只到墙顶）。所以**跨出门框音乐就停，和显存释放同进同出**；站在屋顶上也算屋外。

### 「前奏 + 循环体」：1:16.05 → 2:31.90

用户 2026-11-11：「结束处接1分16左右一直循环可以做到吗」→ 随后更正为
**「应该是 1:16.05 到 2:31:90」** → 2026-11-12 微调起点到 **1:15.99**。

用 Godot 导入期的 `loop_offset` 实现，`art609_theme.ogg.import` 里是：

```ini
loop=true
loop_offset=75.9992
```

含义：**0 → 1:15.9992 的前奏只播一次**，之后 **1:15.9992 → 2:31.90（75.90 s）反复**。
音频文件总长是 **151.9000 s**（源 154.1547 s，切掉最后 2.2547 s）。

**起点为什么是 75.9992 而不是用户说的 75.99**：75.99 那一点波形是断的 ——

```
终点 2:31.90 固定，内部相邻样点平均跳变 = 0.009757
  起点 75.990 s：跳变 0.283157（×29.0）  ← 会「咔」
  起点 75.9992 s：跳变 0.003510（×0.36） 斜率差 0.003708  ← 选这个（+9 ms）
```

**9 ms** 完全听不出长短，接缝干净 80 倍。**终点按用户给的 151.90 原样不动**
（那里 RMS 0.244，还在音乐里，不是淡出区）。

⚠️ 这两个时间点都是**源文件的时间轴**。上一版曾把整首切成 144 s 再循环，
那次是错的（用户看到播放器上的时间对不上才发现）。

**演变记录**：起点 `76.3976`（对应 1:16.05 那轮）→ **`75.9992`（本轮 1:15.99）**。

## 循环开关在哪

`gamedev_theme.ogg.import` / `shop_theme.ogg.import` 里的 `loop=true`（以及 `loop_offset=0`）。
这是 Godot 的**导入期**选项，`scripts/music.gd` **不会**在运行期改它 ——
运行期改循环要每帧盯 `finished` 信号再 `play()` 一次，那会有一帧的空隙。

⚠️ 改完 `.import` 的 `loop` 要**强制重导**才生效（只改文件 Godot 不会重导，
因为源文件没变）：删掉 `.godot/imported/<名字>-<哈希>.oggvorbisstr`
和同名 `.md5`，再跑 `godot --headless --path . --import`。
自检脚本里会打印 `loop = true/false`，改完跑一遍就知道有没有生效。

## 代码在哪

- `scripts/music.gd` —— 曲目表（逻辑名 → 文件 + 音量）、播放 / 停止（默认不淡化）
- `scripts/shop.gd::_build_music_zone()` —— 店里的 `Area3D`，玩家进出时开 / 关音乐
  （烘焙场景 `shop_baked.tscn` 里的 `MusicZone` 节点走 `_wire_baked()` 接信号）
- `scripts/gamedev_room.gd::_build_music_zone()` —— 活动室同理；盒子尺寸是**运行时**
  从 `Model/Collision` 的碰撞盒量出来的，房间尺寸怎么改都不会漂
- `scripts/esports_collision.gd::_build_music_zone()` —— 电竞房同理，盒子从
  `BakedCollision/AutoCol` 的 769 个烘焙盒量出来。**多一道可见性判断**：
  这栋房子默认藏着（`game.tscn` 里 `visible = false`，买完才从天而降），
  而 `Area3D` 的监测跟可见性无关 —— 不判的话玩家走过那块空地就会响起 BGM
- `scripts/splat_scene.gd::_update_room_bgm()` —— 画室 609 **不用 Area3D**：
  复用 `_is_inside_room()`（和「出房间释放泼溅」同一套边界），
  在 `game.tscn` 的 `Room609` 节点上填 `room_bgm_track = "room609"` 即可
- `scripts/_verify_music.gd` —— 自检：四个房间的循环开关、进/出播放与停止
  （电竞房那段还验「房子藏着时不出声、现身才出声」；画室 609 那段验
  「屋里放 / 出门停 / 屋顶不算屋里」）
