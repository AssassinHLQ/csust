电竞房碰撞 v5: 修「碰撞重复」—— 去重根本没生效 + 模型自带复制件

使用者 2026-11-09：「为什么碰撞重复了」。

## 查到的两件事
**① 去重函数一直没生效（本喵的 bug）**
`dump_esports_parts.py::dedupe()` 只过滤了 Python 列表，**没有把物体从场景里删掉**；
后面 `meshes = [o for o in bpy.context.scene.objects …]` 又把它们枚举回来。
实测：日志写「删 35 个对象」，最终件数一点没少（还是 728）。
⇒ 改成 `bpy.data.objects.remove(o, do_unlink=True)`。

**② 原始 FBX 里本身就有镜像/复制件**
碰撞里查出 **77 组**「尺寸一模一样、中心只差 3 cm」的盒子，例如
  P0056_0 @(51.36,1.53,13.46) == P0057_0 @(51.36,1.53,13.43)  尺寸 0.06×0.14×0.22
原来的判据有两个漏网处：
  · 中心容差只有 **0.02 m** → 差 0.03 m 就漏了
  · **要求面数相同** → 复制件面数差几个就漏了
⇒ 中心容差放宽到 **0.10 m**（`near_eps`），并且**不再要求面数相同** ——
  对碰撞来说「包围盒一样 + 位置几乎一样」就是冗余，面数无关。

## 结果
  去重：删 **195 个**对象（原来 18 个）
  部件：728 → **533 件**；盒子 1156 → **957 个**
  烘出的形状：829 → **790 个**
  **完全重复的形状 0 个**
  近似重复（跨物体）**77 组 → 25 组**，剩下的都是 0.06×0.06×0.91 的
  **桌椅腿细杆**（模型里本来就是独立的左右腿，位置重合但无害）

## 验证（headless，全过）
  [PASS] 小件确实各自独立（658 个小件）
  [PASS] 地面 y=0.60 / 天花板 / 西墙 / 东墙 / 南墙
  门洞可通行 14/41
  **可走性 668/714 = 94%**
